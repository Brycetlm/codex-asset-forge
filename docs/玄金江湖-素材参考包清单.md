## 生成原则

- 全部使用 Codex / ChatGPT 内置图像生成，不使用需要 API Key 的备用 CLI。
- 图鉴中不烘焙中文文字，不复制现有游戏角色、Logo、图标或完整界面。
- 图鉴用于风格验证和后续生成参考，不直接视为已切分、已命名、已通过边缘验收的最终游戏素材。
- 全部中间图和偏题图也保存在素材包的 `intermediate/` 中，不删除；详情由 `manifest.json` 的 `generationLog` 追踪。
- 机器读取时以素材包内的 `manifest.json` 为准，无须通过视觉识别重新推断每个格子的内容。
