# 玄金江湖·武侠修仙 UI 风格规范

## 风格定位

精致的中国古代武侠修仙 RPG 界面美术，整体采用暗色墨金风格。界面本身是高清二维手绘，不是粗颗粒像素画；只有小比例角色和个别图标可以带有高细节像素插画感。

## 自定义风格初始描述

```text
精致的中国古代武侠修仙 RPG 界面美术，整体采用暗色墨金风格，不是粗颗粒像素画。界面以接近黑色的暖灰、深褐色和墨蓝色为底，使用纤细、克制的古铜金线条勾勒边框，转角带有简化的中式回纹、如意纹和菱形装饰。

面板内部保持大面积深色留白，边框层级清晰但装饰不能过度复杂。按钮、标签页和卡片采用扁平的二维正视图，不要透视。普通状态为深黑底和暗金细边；选中、悬停和重要操作状态使用温暖的琥珀金色内发光，边缘带少量金色粒子和柔和光晕，像烛火照亮古铜器，但不要做成霓虹灯。

技能、武学和法术图标采用精致的手绘游戏图标风格，底色以深蓝、靛青、紫色和黑色为主。外功、剑法和身法使用青蓝色、银白色的弧形气劲、剑光和速度线；内功和修炼类图标使用青绿色灵气、阴阳、经脉、莲花、掌印和打坐剪影；稀有技能可以使用紫色，最高级技能使用克制的金色和赤橙色。特效明亮但必须被限制在方形图标内部，图标轮廓清楚，缩小后仍能辨认。

道具图标采用精致的小型手绘物件，包括竹简、玉佩、铜钱、丹药、酒葫芦、香炉、罗盘、令牌、符箓、武器和生活用品。物件使用暖灰、旧金、木色、玉色和少量朱砂红，具有柔和的体积光与材质细节，背景保持深色，不出现现代物品。

角色和敌人小图可以带有高细节像素插画感或小比例二维手绘感，轮廓清晰，服装参考中国古代江湖人物、门派弟子、僧人、剑客和侠士。角色姿势具有辨识度，但不要复制任何现有游戏角色、服装或动作。

完整界面采用规整、紧凑的信息布局：顶部为横向分类标签，中间为两到三个金边深色面板，右侧可放技能格或物品格，底部为横向属性栏、状态图标和红蓝资源条。所有面板、按钮、图标槽和属性栏必须使用统一的暗金边框粗细、转角结构、光照方向和选中高光。

界面背后可以隐约出现低饱和度的中国古代建筑、雪山、山水、城镇或江湖场景，并进行明显虚化和降对比处理，不能影响前景信息阅读。整体氛围成熟、沉静、精致、神秘，兼具武侠江湖的厚重感和修仙法术的灵动感。
```

## 验证样张生成规格

- 16:9 横向综合 UI 风格板。
- 顶部包含五个无文字横向标签，其中一个是琥珀金选中状态。
- 左侧为武学修炼面板，中间为技能详情面板，右侧为 4×4 技能图标格。
- 底部包含属性图标栏与红蓝资源条。
- 背景是低对比、虚化的雪山古城或江湖建筑。
- 不出现可读文字、游戏 Logo、角色立绘或透视展示。
- 这张图用于确认风格，不作为可直接发布的最终 UI。

## 使用建议

1. 自定义风格可同时上传一张完整界面截图和一张技能图标合集作为风格参考。
2. 生图时不要让模型烘焙中文文字，只预留文字安全区，再在 Godot、Unity 或 Web 界面中叠加文字。
3. 技能图标、道具图标和角色小图应分开生成，避免单张图中混入不一致的像素密度。
4. 参考现有游戏时，只提取配色、材质、布局和光照规则，不复制角色、标志、文字、具体图标或完整界面。
